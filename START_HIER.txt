SHORTS MAKER — START HIER
=========================

1. Diesen Ordner entpacken (z.B. nach ~/shorts).
2. Datei öffnen:  ANLEITUNG_MARIUS.md

WICHTIG auf macOS (Homebrew-Python):
- NICHT: python3.14 -m pip install -e .
- SONDERN: erst venv anlegen (sonst „externally-managed-environment“)

Einmalig einrichten:

  cd ~/shorts
  python3.14 -m venv .venv
  source .venv/bin/activate
  python -m pip install -U pip
  python -m pip install -e .
  python scripts/demo_local.py

Danach bei jedem neuen Terminal:

  cd ~/shorts
  source .venv/bin/activate
  python -m shorts_maker "https://www.youtube.com/watch?v=VIDEO_ID" -o output --model small --force-transcribe

Oder alles auf einmal:  bash setup.sh

Fertige Shorts:  output/shorts/
