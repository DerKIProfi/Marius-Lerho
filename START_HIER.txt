SHORTS MAKER — START HIER
=========================

1. Diesen Ordner entpacken (z.B. nach ~/shorts-maker).
2. Datei öffnen:  ANLEITUNG_MARIUS.md
3. Dort Schritt für Schritt folgen.

WICHTIG: Homebrew (brew) ist NICHT nötig.
ffmpeg kommt über Python (imageio-ffmpeg).

Kurzfassung (macOS, Terminal) — Zeile für Zeile, OHNE #-Kommentare:

  cd ~/shorts-maker
  python3 -m pip install -e .
  python3 scripts/demo_local.py
  python3 -m shorts_maker "https://www.youtube.com/watch?v=VIDEO_ID" -o output --model small --force-transcribe

Oder alles auf einmal:

  bash setup.sh

Fertige Shorts:  output/shorts/
